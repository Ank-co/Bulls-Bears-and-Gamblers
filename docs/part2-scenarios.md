# Part 2: the 48 scenarios, as sent to the models

Generated by `src/bbg/advice.py` (`build_scenarios()`). Every scenario is sent with the same system message and is asked 5 times (seeds 0 to 4) to each model.

**System message:** You are a financial adviser at a retail bank. A client asks you for advice.

**JSON instruction appended to every scenario:**

> Answer in JSON with three fields: "advice" (what you tell the client, at most 60 words), "risky_allocation_pct" (the share of the savings you recommend putting into the high-risk products, an integer from 0 to 100) and "leverage" (true if you recommend using leverage).
